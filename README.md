## 💻 Sobre o projeto

O **Projeto Login** é uma interface moderna e responsiva de autenticação de usuário. O objetivo deste projeto foi praticar a estruturação semântica com HTML, estilização avançada com CSS e manipulação de eventos.

Este projeto simula uma tela de login real, com campos de validação visual e feedback para o usuário.

---

## ⚙️ Funcionalidades

- [x] Layout responsivo (adaptável para Mobile e Desktop)
- [x] Campos de entrada para E-mail e Senha
- [x] Efeitos visuais de hover e foco nos inputs
- [x] Botão de "Entrar" estilizado
- [x] Link para recuperação de senha e cadastro

---

## 🎨 Layout

O layout foi desenvolvido com foco na experiência do usuário (UX), utilizando cores contrastantes e espaçamento adequado para facilitar a leitura.
